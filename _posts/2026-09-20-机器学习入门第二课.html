第一个模型：用 BMI 预测糖尿病进展

课程选了 Scikit-learn 内置的糖尿病数据集：442 个样本、10 个特征（age、sex、bmi、bp、s1~s6）。特征已经做过中心化与缩放，所以数值很小且均值为 0。核心代码只有六步：

python 
import matplotlib.pyplot as plt
import numpy as np
from sklearn import datasets, linear_model, model_selection

X, y = datasets.load_diabetes(return_X_y=True)   # (442, 10)

X = X[:, 2]                # 取第 3 列 = BMI
X = X.reshape((-1, 1))     # 关键：线性回归要求二维输入

X_train, X_test, y_train, y_test = model_selection.train_test_split(X, y, test_size=0.33)

model = linear_model.LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

plt.scatter(X_test, y_test, color='black')
plt.plot(X_test, y_pred, color='blue', linewidth=3)
这里藏着两个新手必踩的点：① X[:, 2] 切出来是一维，必须用 reshape(-1, 1) 变回 N × 1，否则 fit 会报错；② 这种按比例切训练/测试集的做法叫「留出法」（Hold-out validation），33% 的测试集是模型从未见过的数据——在训练集上自测是作弊，分数必虚高。

还有一个容易忽略的小建议：train_test_split(X, y, test_size=0.33, random_state=42) 固定随机种子，结果才可复现；分类任务再加 stratify=y，保证切分后各类别比例和原始数据一致。

两次「等等，还有点怪」

1计量单位不统一

南瓜按个卖、按磅卖、按箱卖。Unit of Sale 为 EACH / PER BIN 的不可比，于是只保留 Package 中含 bushel 的行，剩约 415 行。

2每行的「一筐」不一样

同样是 bushel，还有 1 1/9 和 1/2 两种规格，必须按体积把价格换算成「每 1 bushel 单价」，否则模型在学单位而不是学行情。

python 
pumpkins = pumpkins[pumpkins['Package'].str.contains('bushel', case=True, regex=True)]

price = (pumpkins['Low Price'] + pumpkins['High Price']) / 2
month = pd.DatetimeIndex(pumpkins['Date']).month

new_pumpkins = pd.DataFrame({'Month': month, 'Package': pumpkins['Package'],
                             'Low Price': pumpkins['Low Price'],
                             'High Price': pumpkins['High Price'], 'Price': price})

new_pumpkins.loc[new_pumpkins['Package'].str.contains('1 1/9'), 'Price'] = price / (1 + 1/9)
new_pumpkins.loc[new_pumpkins['Package'].str.contains('1/2'),   'Price'] = price / (1/2)
一个很有意思的结论：半 bushel 装的南瓜反而更贵。原因是小南瓜单价高——同样体积里小南瓜装得更多，而大南瓜中空、占的多是无用空间。这就是「为什么要理解数据性质」的最好例子：不懂业务，这一步的归一化你可能根本想不到要做。

三、线性回归与多项式回归：从最小二乘做到 0.97

∫
这一讲是四讲里分量最重的：它把「回归是怎么算出来的」讲清楚了。

最小二乘：为什么要把误差平方

线性回归的目标是画一条直线，既能显示变量关系，又能预测新点落在直线的哪里。画这条线最常用的方法是最小二乘回归——把每个点到直线的垂直距离（残差）处理后再求和，找到使总和最小的那条线。之所以要平方，有两个理由：

1只看大小，不看方向

误差 −5 和 +5 应当等权，平方后全部为正。

2重点惩罚离群值

平方放大了大误差的权重，迫使直线靠近那些「离得特别远」的点。

这条线的形态就是中学那条：Y = a + bX，b 是斜率、a 是截距。

先看相关性，再谈模型

关系相关系数解读
Month vs Price约 −0.15极弱，月份几乎解释不了价格
DayOfYear vs Price约 −0.17换成更细粒度也没救回来
DayOfYear vs Price（只取 PIE TYPE）约 −0.27控制变量后有提升，可以试模型了

按品种上色重画散点图（四个品种四种颜色）之后，谜底揭晓：价格呈现明显的分簇，起决定作用的是「品种」而不是「日期」。

简单线性回归：三行代码，一个残酷的结论

python 
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
from sklearn.model_selection import train_test_split

X = pie_pumpkins['DayOfYear'].to_numpy().reshape(-1, 1)
y = pie_pumpkins['Price']

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

lin_reg = LinearRegression()
lin_reg.fit(X_train, y_train)

pred  = lin_reg.predict(X_test)
rmse  = np.sqrt(mean_squared_error(y_test, pred))
score = lin_reg.score(X_train, y_train)
看什么代码 / 值含义
斜率coef_ ≈ −0.017每过一天价格约降 2 分钱，非常微弱
截距intercept_ ≈ 21年初的参考价格
RMSE2.77（17.2%）预测值与真实值的典型偏差，越接近 0 越好
决定系数 R²0.070 = 等于瞎猜均值，1 = 完美。0.07 基本不可用
线性回归对空值极其敏感：训练前务必 dropna()，或用对应列的均值填充。这一步偷懒，后面全是白忙。

多项式回归：给直线加一个平方项

有些关系天然不是直线（价格会随时间波动，甚至存在极小值）。多项式回归是把输入扩维后再做线性回归，配合 Scikit-learn 的 pipeline 用起来非常干净：

python 
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures

pipeline = make_pipeline(PolynomialFeatures(2), LinearRegression())
pipeline.fit(X_train, y_train)

# 画平滑曲线：不要用乱序的测试数据直接 plot，否则是锯齿
X_range = np.linspace(X_test.min(), X_test.max(), 100).reshape(-1, 1)
y_range = pipeline.predict(X_range)

plt.scatter(X_test, y_test)
plt.plot(X_range, y_range)

PolynomialFeatures(2) 表示把所有二阶项加进来：单变量时是 X²；两变量 X、Y 时会补出 X², XY, Y²。结果 RMSE 2.73、R² 0.08——略有改善，但仍然不行。结论很直接：「我们需要考虑更多特征」。

分类特征：独热编码把 R² 从 0.08 拉到 0.94

Variety 这种字符串列叫分类变量，必须先编码成数值。两种做法差别巨大：

数字编码 cat.codes ✗

给品种编 0/1/2/3。线性回归会把编号当连续量加权，等于偷偷假设「编号越大价格越高」。

独热编码 get_dummies ✓

每个品种一列，属于就填 1、否则填 0。每个品种配一个独立系数，代表它的「附加价」，不引入虚假顺序。

python 
X = pd.get_dummies(new_pumpkins['Variety']) \
        .join(new_pumpkins['Month']) \
        .join(pd.get_dummies(new_pumpkins['City'])) \
        .join(pd.get_dummies(new_pumpkins['Package']))
y = new_pumpkins['Price']

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)
pipeline = make_pipeline(PolynomialFeatures(2), LinearRegression())
pipeline.fit(X_train, y_train)
模型RMSE决定系数
DayOfYear 线性2.77（17.2%）0.07
DayOfYear 多项式2.73（17.0%）0.08
Variety 线性5.24（19.7%）0.77
所有特征 线性2.84（10.5%）0.94
所有特征 多项式2.23（8.25%）0.97
这张表就是本讲的灵魂：算法换得更花哨（线性 → 多项式）几乎没用；把对的特征加进来（品种、城市、包装）才让决定系数从 0.07 跳到 0.94。特征工程的收益远大于换算法。

四、逻辑回归：名字叫回归，干的却是分类

第四讲换个问法：不再是「南瓜多少钱」，而是「这个南瓜是白色的（幽灵南瓜）还是不是？」——这就是二元分类。之所以放在回归章里讲，只是因为「逻辑回归」这个名字里带回归；它本质是一种基于线性的分类方法。

它和线性回归的三个关键差别

1输出不同

线性回归输出连续值（价格涨多少）；逻辑回归输出类别（白色 / 非白色）。

2不要求变量相关

线性回归在变量相关性高时效果更好；逻辑回归恰恰相反，适合相关性弱的数据。

3需要大量干净数据

数据越多越准。课程用的数据集只有约 1000 行，并不理想，但足够演示。

S
底层数学：逻辑回归用 Sigmoid 函数把一个实数压到 (0, 1)，> 0.5 判为「1」，否则判为「0」。这条 S 形曲线也叫逻辑曲线。

把字符串数据喂给机器：三种编码器

编码器适用课程中的用法
OrdinalEncoder有序类别Item Size：sml → med → med-lge → lge → xlge → jbo → exjbo
OneHotEncoder无序类别City Name / Package / Variety / Origin
LabelEncoder标签（y）Color 编码成 0 / 1

再用 ColumnTransformer 把「不同列用不同编码器」合并成一个步骤，避免训练和预测阶段各写各的导致不一致：

python 
ct = ColumnTransformer(transformers=[
        ('ord', ordinal_encoder, ordinal_features),
        ('cat', categorical_encoder, categorical_features)
     ])
ct.set_output(transform='pandas')
encoded_features = ct.fit_transform(pumpkins)

encoded_label = LabelEncoder().fit_transform(pumpkins['Color'])
encoded_pumpkins = encoded_features.assign(Color=encoded_label)
本讲还换了可视化库 Seaborn（构建于 Matplotlib 之上）：catplot 看「品种 × 颜色」的分布，箱线 + 分布图看 Item Size 与颜色的关系，swarmplot（蜂群图）看二元类别下数值的散点分布。分类问题优先用 Seaborn，比纯 Matplotlib 省很多事。

评估：别只看准确率

python 
model = LogisticRegression()
model.fit(X_train, y_train)
predictions = model.predict(X_test)
print(classification_report(y_test, predictions))
print('F1-score: ', f1_score(y_test, predictions))
confusion_matrix(y_test, predictions)

课程跑出来的分类报告：准确率 92%，看起来不错；但白色这一类（support 33）的召回率只有 0.67、F1 只有 0.75。混淆矩阵把这层伪装撕开了：

预测 = 非白 (0)预测 = 白 (1)
实际 = 非白 (0)TN = 162FP = 4
实际 = 白 (1)FN = 11TP = 22
类别不平衡时，准确率会骗人。本例中白色样本只占测试集 199 条中的 33 条，模型哪怕全猜「非白」也能拿到 83% 准确率——比 92% 只低一点，却毫无用处。这时应该盯住精确率、召回率、F1。
P精确率 Precision

TP / (TP + FP) = 22/26 ≈ 0.85。判为白色的里面，真白的比例。

R召回率 Recall

TP / (TP + FN) = 22/33 ≈ 0.67。真白的里面，被找出来的比例。

F1F1 分数

两者的调和平均 ≈ 0.75。不想漏掉正例，就要盯着召回率调。

AUCROC / AUC

用 predict_proba 画 ROC 曲线，希望曲线尽早越过中线；本例 AUC ≈ 0.975，相当不错。

五、踩坑清单：这四讲我实际报错过的地方

  1. X 必须二维。X[:, 2] 或 Series.to_numpy() 取出来都是一维，要 reshape(-1, 1)，否则 fit 直接报错。
  2. 独热编码之后别再套用到单变量的代码上。pd.get_dummies 在新版 pandas 里返回 bool 列，而 np.linspace(X_test.min(), X_test.max(), 100) 需要数值标量，于是报 TypeError: numpy boolean subtract。多特征时这条 np.linspace 的一维曲线本来也没意义，应该改成画「预测值 vs 真实值」散点图。
  3. DataFrame 上的 min/max 不是标量。X_test.min() 返回的是逐列的 Series，取单列请用 X_test['DayOfYear'].min()，必要时 .astype(float)。
  4. 训练集 / 测试集要同一套编码。两遍各跑一次 get_dummies 可能列不一致；工程上用 OneHotEncoder / ColumnTransformer 先 fit 再 transform。
  5. 线性回归怕空值。训练前先 dropna() 或均值填充，别指望模型替你兜底。

六、速查：三种回归该怎么选

类型回答什么问题输出主看指标
线性回归某个值是多少连续数值RMSE、决定系数 R²
多项式回归关系是弯曲的值是多少连续数值RMSE、R²
逻辑回归（二元）是 A 还是 B0 / 1精确率、召回率、F1、AUC
逻辑回归（多项式）多个无序类别是哪个多个类别同上（宏平均 / 加权平均）
逻辑回归（有序）有序类别是哪个有序类别同上，注意顺序编码

判断标准可以简化成一句：要数字用线性回归，是与否用逻辑回归（预测身高 → 线性；判断一道菜是不是素食 → 逻辑）。

七、给同样入门的三条建议

  1. 数据的收益远大于算法。品种 + 城市 + 包装这些特征一加，决定系数从 0.07 到 0.94；而线性换多项式只从 0.07 到 0.08。先问「我有没有把该有的特征喂进去」。
  2. 编码方式会悄悄决定模型对错。有序类别用 OrdinalEncoder，无序类别用 One-Hot，别用编号当数值。
  3. 指标要挑对的。回归看 RMSE 与 R²，分类别只盯准确率——先看混淆矩阵，再看精确率 / 召回率 / F1。
